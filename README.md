# Excel-Project
## Project objective 
To analyze 5,007 finance transactions worth ₹45.61 Cr using Advanced Excel to track revenue performance, understand customer behaviour, and identify reasons behind 10.19% failed transactions. The project aims to convert raw transaction data into an interactive dashboard with KPIs, charts, and slicers to help business reduce failures and increase revenue.

## Dataset used
- <a href ="https://github.com/Namrata313/Excel-Project/blob/main/Finanace%20data.xlsx">

## Question KPI
Questions (KPI)
 -What is the Total Transaction Amount?
 -How many Total Transactions are there?
 - What is the Average Transaction Value?
 -What is the Transaction Success Rate?
 -What is the Failed Transaction Rate?
 -What is the Pending Transaction Rate?
 -What is the Total Fees Collected?
 -What is the Total Taxes Collected?
 -Which State has the Highest Revenue?
  -Which Customer Segment gives the Highest Revenue?


## Process
* Verify data for any missing values and anomalies, and sort out the same.
* Made sure data is consistent and clean with respect to data type, data format and values used.
* Created pivot tables according to the questions asked.
* Merge all pivot tables into one dashboard and apply slicer to make dynamic.

## Project Insight

 Total 5,007 transactions worth ₹45.61 Cr were analyzed.
85.74% transactions were successful and 10.19% were failed.Maharashtra gave the highest revenue.Retail segment gave 60% of total revenue
.Female customers did more transactions than male customers.
January had the highest transactions and September had the lowest.
Wednesday had the highest transactions and Monday had the lowest.
Average transaction value was ₹91,100 


## Final Conclusion
This project successfully analyzed 5,007 finance transactions worth ₹45.61 Cr.The business is performing well with 85.74% success rate.But 10.19% failed transactions is a major problem and revenue loss.Maharashtra and Retail segment are the main drivers of revenue.January and Wednesday are the peak periods for transactions.The interactive dashboard helps to track KPIs easily with slicers.By fixing payment failures, business can increase revenue and customer trust.
